# Bugin — сервер

Сервер приложения [Bugin](https://github.com/adikobth-ux/bugin) «Чем заняться сегодня?».
Python 3.12 + FastAPI.

**Этап 0:** тестовые данные прототипа (8 мест и 8 событий Астаны на русском и казахском),
AI-поиск по ключевым словам, «Собрать мне вечер». Без входа и личных данных: избранное,
профиль и история поиска пока хранятся на телефоне.

## Контракт

Описание запросов и ответов — [docs/api.md](docs/api.md). Живая документация сервера —
`/docs`, схема — `/openapi.json`. Язык ответа выбирается заголовком `Accept-Language`
(`kk…` → казахский, иначе русский).

## Запуск у себя

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
uvicorn app.main:app --reload        # http://127.0.0.1:8000/docs
```

Приложение на этот сервер: в папке `bugin`

```bash
flutter run --dart-define=BUGIN_API_URL=http://10.0.2.2:8000   # эмулятор Android
```

## Тесты

```bash
python -m pytest -q        # всё, нужны зависимости из requirements-dev.txt
python -m unittest discover -s tests -t .   # логика без зависимостей
ruff check .
```

`tests/contract` — образцы ответов, те же, что `test/fixtures/api` в приложении.
Тесты сверяют с ними имена полей, поэтому контракт не разъедется незаметно.
Меняете поле — меняйте образцы в обоих репозиториях.

## Бесплатный сервер на Render

1. Зарегистрироваться на [render.com](https://render.com) через GitHub (карта не нужна).
2. New → Blueprint → выбрать репозиторий `bugin-backend`. Render прочитает `render.yaml`
   и создаст сервис `bugin-api` (бесплатный тариф, Франкфурт).
3. Адрес вида `https://bugin-api-xxxx.onrender.com` — проверить: `/health`, `/docs`.
4. В репозитории приложения: Settings → Secrets and variables → Actions → Variables →
   `BUGIN_API_URL` = этот адрес. Следующая сборка APK и веб-версии пойдёт на сервер.

Ограничения бесплатного тарифа: после 15 минут без запросов сервер засыпает,
первый запрос после паузы идёт около минуты. Сервер не в Казахстане — поэтому
здесь только тестовые данные; до первых пользователей переезжаем в казахстанское облако.

## Устройство

```
app/
├── main.py          приложение FastAPI: роутеры, CORS, ошибки в формате контракта
├── clock.py         местное время Казахстана (UTC+5)
├── lang.py          язык ответа по Accept-Language
├── api/             HTTP-слой: схемы pydantic и роутеры /v1
└── domain/          логика без веб-фреймворка
    ├── catalog_data.py   тестовые данные (перенесены из приложения)
    ├── catalog.py        места и события на нужном языке
    ├── search.py         разбор запроса и подбор
    ├── planner.py        «Собрать мне вечер»
    └── texts.py          числа и подписи как в приложении
```

Логика повторяет mock-реализацию приложения, поэтому приложение с сервером и без него
ведёт себя одинаково. Следующий этап — база PostgreSQL, админка для наполнения,
вход по SMS и разбор запроса через Claude.
