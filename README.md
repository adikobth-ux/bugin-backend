# Bugin — сервер

Сервер приложения [Bugin](https://github.com/adikobth-ux/bugin) «Чем заняться сегодня?».
Python 3.12 + FastAPI, база PostgreSQL (Neon).

Что умеет:

- места и события Астаны на русском и казахском — из каталога в базе;
- **админка** `/admin`: вносить и править места и события, фото, скрывать, удалять;
- AI-поиск по ключевым словам и «Собрать мне вечер» — по тому, что есть в каталоге.

Входа и личных данных пока нет: избранное, профиль и история поиска хранятся на телефоне.

## Контракт

Описание запросов и ответов — [docs/api.md](docs/api.md). Живая документация сервера —
`/docs`, схема — `/openapi.json`. Язык ответа выбирается заголовком `Accept-Language`
(`kk…` → казахский, иначе русский).

## Настройки

Переменные окружения (на Render — bugin-api → Environment):

| Переменная | Что это | Без неё |
|---|---|---|
| `DATABASE_URL` | строка подключения Neon, `postgresql://…` | каталог в памяти, правки пропадают при перезапуске |
| `ADMIN_PASSWORD` | пароль админки | админка выключена |
| `PUBLIC_URL` | внешний адрес для ссылок на фото | на Render не нужна — берётся `RENDER_EXTERNAL_URL` |
| `SEED_DEMO` | `0` — не заводить тестовые данные в пустую базу | тестовые данные заводятся один раз |

Таблицы сервер создаёт и обновляет сам при старте (`app/storage/postgres.py`, список
`MIGRATIONS`). Если база недоступна, новый деплой не стартует, а Render оставляет работать
прежнюю версию — причина видна в логе деплоя.

## Админка

`https://bugin-api.onrender.com/admin` — вход по паролю из `ADMIN_PASSWORD`, сессия на 30 дней.
Сделана под телефон.

- **Места и события**: тексты по-русски и по-казахски (пустой казахский → в приложении русский),
  категория, адрес, часы, средний чек, кому подходит, настроение, удобства, фото.
- **Координаты** — из ссылки 2ГИС, Google Maps или Яндекс Карт (кнопка «Поделиться»), вручную
  вводить не нужно. Короткие ссылки (`go.2gis.com`, `maps.app.goo.gl`) сервер раскрывает сам.
- **Фото** уменьшаются до 1600 px и хранятся в базе; первое — главное.
- **События**: площадка из каталога подставляет адрес и карту; «Копировать на другую дату»;
  цена «от» считается по категориям билетов; «Купить билет» ведёт на `ticketUrl`.
- **Тестовые данные** помечены «тест» и удаляются одной кнопкой на главной админки.
- Изменения видны в приложении сразу после сохранения.

## Запуск у себя

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
ADMIN_PASSWORD=test uvicorn app.main:app --reload   # http://127.0.0.1:8000/docs и /admin
```

Без `DATABASE_URL` всё работает в памяти. Приложение на этот сервер: в папке `bugin`

```bash
flutter run --dart-define=BUGIN_API_URL=http://10.0.2.2:8000   # эмулятор Android
```

## Тесты

```bash
python -m pytest -q                                   # всё, нужны зависимости из requirements-dev.txt
TEST_DATABASE_URL=postgresql://… python -m pytest -q  # плюс хранилище в PostgreSQL (база очищается!)
python -m unittest discover -s tests -t .             # логика без зависимостей
ruff check .
```

CI поднимает PostgreSQL 16, прогоняет тесты и запускает сервер без базы и с чистой базой.
`tests/contract` — образцы ответов, те же, что `test/fixtures/api` в приложении: тесты сверяют
с ними имена полей. Меняете поле — меняйте образцы в обоих репозиториях.

## Сервер на Render

Сервис `bugin-api` создан из `render.yaml` (Blueprint), бесплатный тариф, Франкфурт:
**https://bugin-api.onrender.com**. Каждый push в `main` Render выкладывает сам.
База — Neon, проект `bugin`, регион AWS Europe Central 1 (Франкфурт).

Ограничения бесплатного тарифа: после 15 минут без запросов сервер засыпает, первый запрос
после паузы идёт около минуты. Сервер и база не в Казахстане — до первых настоящих
пользователей переезжаем в казахстанское облако.

## Устройство

```
app/
├── main.py          FastAPI: роутеры /v1, фото, админка, ошибки в формате контракта
├── config.py        переменные окружения
├── services.py      общие объекты: настройки, хранилище, каталог
├── api/             HTTP-слой: схемы pydantic и роутеры /v1
├── admin/           админка: Starlette + Jinja2, формы, фото, вход
├── storage/         хранилище: PostgreSQL, память, тестовые данные
└── domain/          логика без веб-фреймворка
    ├── catalog.py        каталог на нужном языке: расстояния, цены, скрытые записи
    ├── i18n.py           двуязычные документы {"ru": …, "kk": …}
    ├── geo.py            расстояния, координаты из ссылок на карты
    ├── search.py         разбор запроса и подбор
    ├── planner.py        «Собрать мне вечер»
    ├── catalog_data.py   тестовые данные прототипа
    └── texts.py          числа и подписи как в приложении
```
